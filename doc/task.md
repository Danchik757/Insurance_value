# Описание проекта

Проект — предсказание суммы страховой выплаты (CLAIM_PAID) по данным Ethiopian Insurance Corporation. Данные берутся с Kaggle, два csv-файла за разные периоды (~800к строк суммарно).

Пайплайн состоит из 7 этапов:

1. **Сбор данных** — читаем csv батчами, сохраняем в SQLite (таблица raw_batches). Логируем сколько строк загрузили.

2. **Анализ данных** — смотрим на пропуски, выбросы, распределения. Делаем feature engineering: длительность полиса, отношение премии к числу мест и тд. Результат сохраняется в cleaned_batches.

3. **Подготовка данных** — заполняем пропуски (медиана/мода), кодируем категориальные признаки через LabelEncoder. Масштабируем два варианта: StandardScaler (вариант A) и MinMaxScaler (вариант B).

4. **Обучение** — три модели: Decision Tree, kNN, SGD Regressor. Обучаем на обоих вариантах препроцессинга. SGD поддерживает дообучение через partial_fit. Разбиение временное: 80% train, 20% test.

5. **Валидация** — считаем MAE, RMSE, R2 на тестовой выборке. Сохраняем результаты и выбираем лучшую модель по MAE. Также выводим важность признаков по дереву.

6. **Обслуживание** — лучшая модель копируется как best_model.pkl. Есть функция predict() которая принимает csv, делает предсказания и логирует время/память.

7. **Управление** — точка входа run.py с режимами: полный цикл, inference, update (дообучение), summary, dashboard. Конфиг в config.yaml.

## Результаты

Лучшая модель — kNN (вариант A, StandardScaler). MAE ~10729 на тестовой выборке.

## CI/CD

Используется GitHub Actions — при пуше запускается полный цикл обучения автоматически.

Модели и база данных не коммитятся в репо (бинарники в git — плохая идея), вместо этого сохраняются как артефакты через `actions/upload-artifact`.

Что сохраняется:
- **Логи** — сохраняются даже если обучение упало, чтобы было понятно что пошло не так
- **Модель** — три файла сразу: `best_model.pkl`, `encoders.pkl`, `scaler_A.pkl`, потому что без энкодеров и скейлера модель не запустить
- **База данных** — `database.db` + `db.meta`, в ней хранятся батчи с флагом `used_for_learning`, можно скачать и продолжить дообучение через `python run.py -mode update`
- **Dashboard** — `dashboard.html` + json с метриками. История запусков накапливается в `training_history.json`, который коммитится в репо (добавлено исключение в `.gitignore`). Сводка также пишется в `$GITHUB_STEP_SUMMARY` — видно прямо в интерфейсе гитхаба без скачивания файлов

Скрипт `src/generate_dashboard.py` запускается отдельным шагом после `python run.py` и можно запустить локально тоже.
